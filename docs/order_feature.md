# Order Feature

## Overview

Пользователь может создать заказ, добавив товары в корзину и оформив покупку. Заказ имеет статусы: Draft, Pending, Paid, Shipped, Cancelled.

## Order Creation

- Пользователь добавляет товары в корзину, переходит к оформлению.
- При оформлении создаётся заказ в статусе "Draft" с рассчитанной итоговой суммой.
- После перехода к оплате статус меняется на "Pending".

## Order Cancellation

- Пользователь может отменить заказ, пока он в статусе "Draft" или "Pending".
- После отмены заказ переходит в статус "Cancelled", товары возвращаются на склад.
- Заказ в статусе "Paid" или "Shipped" отменить через обычный интерфейс нельзя — требуется обращение в поддержку.
