# Payment Feature

## Overview

Система позволяет пользователю оплатить заказ банковской картой через внешний платёжный провайдер (Stripe). После успешной оплаты заказ переходит в статус "Paid". После неудачной оплаты заказ остаётся в статусе "Pending" и пользователю показывается сообщение об ошибке.

## Card Payment

Пользователь вводит номер карты, срок действия, CVV. Система валидирует формат полей на клиенте, затем отправляет запрос в Stripe.

- Успешная оплата: карта валидна, средств достаточно → заказ переходит в "Paid", пользователь видит подтверждение.
- Отклонённая карта: Stripe возвращает decline (например, insufficient funds) → заказ остаётся "Pending", показывается сообщение об ошибке с причиной отказа.
- Невалидный номер карты: клиентская валидация должна блокировать отправку формы до обращения к Stripe.

## Refund

Администратор может инициировать частичный или полный возврат средств по оплаченному заказу через панель управления.

- Полный возврат: вся сумма возвращается на карту, заказ переходит в статус "Refunded".
- Частичный возврат: сумма возврата должна быть меньше или равна оригинальной сумме заказа; заказ переходит в статус "Partially Refunded".

## Payment Retry

Если оплата отклонена, пользователь может повторить попытку с той же или другой картой без пересоздания заказа.
